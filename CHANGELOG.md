# История версий JARVIS

## [1.0.0] - 2026-10-04

### Добавлено

- Установщик для Windows (один .exe)
- Анализ железа — рекомендация модели по VRAM
- Автоустановка Ollama
- Автоскачивание модели (qwen3.5:9b или qwen2.5:1.5b)
- Автоустановка Python 3.11
- Автоустановка Ollama Herd
- JARVIS UI на PyQt6 (стеклянная тема)
- Живой прогресс установки (5 этапов)
- Тёмная и светлая темы
- Голосовой ввод (Whisper)
- Синтез речи (Piper)
- Память в JARVIS_DATA
- BAT-лаунчер для ярлыка

### Исправлено

- {autopf} — работает без диска D:
- ReadKey — скрипты не зависают
- PATH — полные пути к ollama/python/herd
- Python — автоустановка
- config.py — относительные пути
- voice.py — переменная JARVIS_DATA
- Модель — совместимость с Python 3.11

### Известные проблемы

- Whisper скачивается при первом запуске (2-5 минут)
- На CPU работает медленнее
- HuggingFace может выдавать предупреждения о симлинках

- Расширение навыков
