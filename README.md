# JARVIS  окальный AI-ассистент для Windows

**JARVIS**  локальный AI-ассистент, работающий полностью **на вашем компьютере**. икаких облаков, никакой телеметрии. аши данные остаются у вас.

##  то умеет

-  **бщаться**  через красивый стеклянный интерфейс
-  **Слушать голос**  через микрофон (Whisper)
-  **оворить**  голосом (Piper TTS)
-  **ыполнять команды**  открывать программы, работать с файлами
-  **омнить**  долговременная память о пользователе
-  **роверять железо**  анализировать ваш 

##  Системные требования

| омпонент | инимум | екомендуется |
|-----------|---------|---------------|
| **С** | Windows 10 (1809+) | Windows 10/11 (64-bit) |
| **RAM** | 8  | 16+  |
| **иск** | 20  | 30+  |
| **GPU** | е требуется | NVIDIA RTX 20+ (8+ ) |
| **нтернет** | Только при установке |  |

**С GPU:** работает **быстро**.
**ез GPU:** работает **на CPU**, но **медленнее** (530 сек).

##  становка

### ыстрый старт

1. **Скачайте** `JARVIS_Setup.exe`
2. **равой кнопкой**  **апуск от имени администратора**
3. **ройдите мастер установки**  5 шагов
4. **ождитесь завершения**  3060 минут
5. **отово!** а рабочем столе  ярлык `JARVIS`

### то делает установщик

1. **нализ железа**  рекомендация модели
2. **становка Ollama**  движок AI
3. **Скачивание модели**  `qwen3.5:9b` или `qwen2.5:1.5b`
4. **становка Python 3.11**
5. **становка Ollama Herd**
6. **Создание venv**
7. **становка PyQt6**
8. **Создание ярлыков**

одробно: [INSTALL.md](INSTALL.md)

##  ервый запуск

1. **айдите ярлык** `JARVIS` на рабочем столе
2. **войной клик**  откроется окно
3. **одождите 3060 секунд**  загрузка Whisper
4. **апишите** `привет`  JARVIS ответит

ервый запуск  **25 минут** (скачивается Whisper).

##  нтерфейс

-  **Тёмная и светлая темы**  переключатель справа вверху
-  **ат**  история диалога
-  **MIC**  голосовой ввод
-  **Send**  отправить
-  **ульсация**  когда JARVIS думает

##  ешение проблем

| роблема | ешение |
|----------|---------|
| становщик не запускается | апустите от админа |
| SmartScreen предупреждает | одробнее  ыполнить в любом случае |
| шибка pip | роверьте интернет |
| JARVIS не отвечает | роверьте `ollama list` |
| Whisper долго грузится | дите 25 минут |

одробно: [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

##  астые вопросы

**ужен ли интернет?**
Только при установке. осле  работает **оффлайн**.

**аботает без GPU?**
а, но **медленнее**. становщик выберет подходящую модель.

**Сколько занимает места?**
~10 .

**ожно ли поменять модель?**
а, в `config.py`.

**ак удалить?**
араметры  риложения  JARVIS  далить.

ольше: [FAQ.md](FAQ.md)

##  Структура после установки
C:\Program Files\JARVIS_INSTALLER
├── scripts\ ← PowerShell-скрипты
├── JARVIS\ ← Python-код UI
├── .venv\ ← виртуальное окружение
├── hardware.json ← отчёт о железе
└── jarvis_icon.ico

C:\JARVIS_DATA\ ← данные
├── memory\ ← память
├── logs\ ← логи
├── notes\ ← заметки
└── voices\ ← голоса Piper
