# JARVIS — Локальный AI-ассистент для Windows

**JARVIS** — локальный AI-ассистент, работающий полностью **на вашем компьютере**. Никаких облаков, никакой телеметрии. Ваши данные остаются у вас.

## 🎯 Что умеет

- 💬 **Общаться** — через красивый стеклянный интерфейс
- 🎤 **Слушать голос** — через микрофон (Whisper)
- 🔊 **Говорить** — голосом (Piper TTS)
- ⚙️ **Выполнять команды** — открывать программы, работать с файлами
- 🧠 **Помнить** — долговременная память о пользователе
- 📊 **Проверять железо** — анализировать ваш ПК
